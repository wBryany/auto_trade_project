# 突破失效与提前退出：2026-09-06

## 修改范围

主分支新增两个独立开关，StrategyConfig 默认关闭，主分支配置开启：

- traditional_invalidate_failed_breakouts：突破信号延续或移交给动能/成交量确认时，如果后续已收盘 K 线回到原突破水平，则删除该突破资格。随后重新站回也不会复活旧信号，但允许形成新的独立突破。交叉和回踩信号资格不受影响；仅影线穿越不会使信号失效。多空对称。
- enable_breakout_failure_exit：仅对带原突破价记录的标准 5m 突破/跌破单启用。入场后连续两根完整5m K线收盘处于突破位不利一侧，同时连续两根1m收盘低于/高于快均线且MACD动能不利、当前价仍未收复突破位，才主动退出。检查已收盘、连续性与新鲜度，不能利用入场前或未收盘K线触发。

突破位记录在原入场 signal.reasons 的 breakout_level 字段中，沿用现有持仓存储机制保存/恢复，不随滚动窗口移动。旧持仓没有该字段时保持原管理逻辑。原交易所硬止损不改动；保护止损及现有动态止损仍优先。实盘、模拟盘和历史回放共用条件；回放在条件确认后的下一根1m开盘模拟新退出。
